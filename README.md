# BDC Conseil – Cabinet

Site vitrine (page d'accueil) du cabinet **BDC Conseil**, cabinet de conseil aux entreprises : création, gestion, organisation et digital.

## Public visé

TPE, PME, artisans, commerçants, professions libérales, commerçants non sédentaires.

## Contenu du site

- Services proposés
- Pour qui
- Méthode de travail
- Valeurs
- Contact

## Technique

- Site statique : une seule page HTML (`index.html`), sans dépendance à installer.
- Publication possible via GitHub Pages (Settings → Pages → branche `main`, dossier `/ (root)`).
